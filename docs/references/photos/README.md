# Références visuelles Taxi Kmer

Collecte consolidée au 15 novembre 2026.

- 5 archives antérieures : 52 photos et 2 planches.
- Lot 06 : 3 photographies + 55 vues provenant d’aperçus vidéo et 4 nouvelles planches.
- Total : 110 images de référence et 6 planches = 116 fichiers image.

Ouvrir index.html pour parcourir les images. inventaire.json contient les dimensions et SHA-256 de chaque fichier. Lire les notices propres à chaque lot pour les sources, crédits et réserves géographiques.

Le lot 04 côté Mont Fébé est HORS TRAJET. Les vues du lot 06 de Bastos sont un contexte provenant d’un autre itinéraire ; la liaison précise Tongolo–Bastos reste à documenter.

Ces fichiers restent dans docs/references/photos : aucun ajout aux ressources Unity.

Les noms sont préfixés par le lot et le sous-dossier pour faciliter l’envoi par l’interface GitHub. correspondance_chemins.json conserve la correspondance exacte avec l’arborescence d’origine. Les notices historiques conservent leurs chemins d’origine.
